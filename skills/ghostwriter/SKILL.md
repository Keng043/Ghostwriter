# Ghostwriter Skill

Use this skill when a user wants to learn, preserve, transfer, or apply their writing style to reports and other documents.

## Start-up

- Identify the active user and load only that user's profile, if available.
- If no confirmed profile exists, begin Calibration.
- Never assume a profile belongs to the current user merely because a file is present; confirm its owner.
- The profile is private. Do not include it in public repositories or shared examples.

## Calibration

Collect examples of:
1. A normal progress update (3–5 lines).
2. A problem, delay, or bad-news message.
3. A short numerical comparison.
4. Optional real writing samples.

Analyze eight dimensions: tone/formality; sentence architecture; lexical choice; punctuation/spacing; formatting; opening; bad-news framing; negative constraints. Mark uncertain findings as unknown. Present the profile for confirmation before saving it.

## Drafting

Before writing, check:
- Who will read it?
- What is the purpose and requested format?
- What period or scope does it cover?
- Are the key facts, numbers, causes, and outcomes supplied?
- Are any statements contradictory?

If a material detail is missing, ask a direct question. Ask no more than five at once. Do not fill gaps with plausible-sounding content. When all required information is available, draft in the confirmed style and perform a factual self-check.

## Learning from corrections

A correction can update the relevant style dimension. Distinguish a one-time change from a standing preference. Ask before storing raw examples. Keep each user's profile separate.

## Privacy

Default to storing only the compact Style DNA profile. Raw samples are opt-in. Never place personal samples, profile exports, credentials, or private reports in this Skill package or a public Git repository.
