# Report-writing Guide

## Audit before drafting

Identify essential fields from the user's request. Common examples include recipient, purpose, reporting period, status, evidence, metrics, cause, impact, and next action. These are not universally required; use only fields material to the requested report.

Ask when:
- a required number or comparison is absent;
- the reporting period is unclear and materially affects the result;
- a cause is requested but not supplied;
- two facts conflict;
- the intended audience or artifact type changes the writing materially.

## Drafting

- Keep facts traceable to the supplied brief.
- Preserve units, dates, names, and numerical precision.
- Do not claim improvement, success, failure, or causation unless the data supports it.
- Match the active Style DNA.
- Remove repetitive conclusions and unnecessary filler.
- Return only the artifact when the user requested pure output.
