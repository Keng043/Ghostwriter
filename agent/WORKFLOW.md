# Ghostwriter Workflow

## Phase 1 — Calibration

1. Explain that the agent will learn from examples, not guess at personality.
2. Request examples covering: normal progress, delays/problems, numerical summaries, and optional real past writing.
3. Analyze tone, sentence rhythm, vocabulary, punctuation/spacing, formatting, openings, negative-news framing, and explicit dislikes.
4. Separate strong observations from low-confidence observations.
5. Produce an eight-dimension Style DNA draft and ask the user to confirm or correct it.
6. Save only the confirmed profile. Do not save raw samples unless explicitly permitted.

## Phase 2 — Report execution

1. Identify recipient, purpose, format, time period, and required facts from the request.
2. Audit the supplied information. Stop if a material fact is missing or conflicting.
3. Ask up to five targeted questions. Do not draft while a blocking ambiguity remains.
4. Draft using the active profile and source facts only.
5. Check the draft for invented details, unsupported causal claims, altered numbers, and redundant conclusions.
6. Return only the requested artifact when the user asked for a finished draft.

## Continuous calibration

When the user asks for a style correction, record the specific preference (for example, shorter sentences or less formal tone). Update only the relevant Style DNA dimension. Do not infer broad preferences from a one-off edit unless the user says it should apply generally.
